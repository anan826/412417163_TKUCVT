=== 故障中（memory=32m + dd 200m，寫入 /dev/shm）===
# docker run --name oom-demo --memory=32m alpine \
#     sh -c 'dd if=/dev/zero of=/dev/shm/big bs=1M count=200'
# docker exit code: 137

# sudo dmesg -T | grep -i "out of memory\|oom" | tail -10

=== 容器狀態 ===
# docker inspect oom-demo --format 'OOMKilled={{.State.OOMKilled}} ExitCode={{.State.ExitCode}}'
OOMKilled=true ExitCode=137

# 說明：exit code 137 = 128 + 9（SIGKILL），即 OOM killer 出手的特徵。
# dd 寫到約 32MB（撞上 memory.max）即被殺，乾淨拿到 137。

=== 回復後（memory=256m，同樣寫 /dev/shm 200m）===
# docker run --name oom-ok --memory=256m alpine \
#     sh -c 'dd if=/dev/zero of=/dev/shm/big bs=1M count=200 && echo DONE'
# docker logs oom-ok | tail
200+0 records in
200+0 records out
209715200 bytes (210 MB, 200 MiB) copied, 0.18 s, 1.2 GB/s
DONE
# exit code: 0
# dmesg 無新增 OOM 訊息

=== 三階段結論 ===
| 項目          | 故障前  | 故障中（32m）              | 回復後（256m） |

| exit code     | -      | 137                       | 0             |
| OOMKilled     | -      | true                      | false         |
| dmesg 關鍵字  | 無 OOM | Memory cgroup out of memory | 無 OOM        |
